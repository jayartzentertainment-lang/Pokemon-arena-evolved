# Platinum Arena 0.9.6 — supplied assets integrated

[Download the new game ZIP](./Platinum-Arena-0.9.6-INTEGRATION.zip).
Extract the 256 MiB `.nds` file and open it in your Nintendo DS emulator.
[Editable source](./Platinum-Arena-0.9.6-SOURCE.zip) is a separate download.

This build adds the actual layered hair/clothing/hat creator, a large portrait
and directional preview, and native Platinum textured battle-menu graphics.
Sourced VFX, wind dashes, natural attacks, stat stages/statuses and stat-driven
beam contests are also integrated. Title L+R+Select opens the Battle Lab.

The user requested immediate delivery before emulator checks finished.
Native compilation and focused core/creator/party tests passed. A short
post-capture recovery input regression is known; other gameplay and native
save/reload are pending user playtesting. This is a development build.
