# Platinum Arena 0.9.5 — combat upgrade

[Download the game ZIP](./Platinum-Arena-0.9.5-INTEGRATION.zip).
Extract the 256 MiB `.nds` file and open it in your Nintendo DS emulator.
[Editable source changes](./Platinum-Arena-0.9.5-SOURCE.zip) are separate.

- Y: equipped move 1; A: move 2; X: move 3/4; L: toggle X's slot.
- B: fixed guard/dodge; double-tap a direction to dash.
- Swift star artwork, contact-timed impacts, and interactive beam pressure.
- At title, hold L + R + Select for the save-isolated 1v1/2v2 Battle Lab.
- During a beam clash, repeatedly tap the firing button to push the contact.

Native compilation and linking completed. Gameplay/emulator tests were not
run, as requested; this build is for your playtesting. Expanded layered
character creation and global followers remain deferred. Only Swift has new
move-specific artwork in this pass; other fallback effects remain.

Read CHANGES.md for scope, READ-ME-FIRST.txt for controls and RELEASE.json for
limitations. Keep a backup of your save when trying a development build.
