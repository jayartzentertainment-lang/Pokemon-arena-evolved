# Platinum Arena 0.9.2 demo

Download `Platinum-Arena-Demo.zip` from this folder, extract it, and open
`Platinum-Arena-0.9.2-DEMO.nds` in melonDS or DeSmuME.

This is an early playable demo of Platinum with live action combat,
character presets/custom colors and corrected sprite mapping/sizes.
294 species use directional animation; other species/forms use native stills.
The full campaign and final save/reload checks remain unfinished.
Controls, exact test limits, credits and licenses are inside the ZIP.
